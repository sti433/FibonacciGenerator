# FibonacciGenerator
🔢 Elegant Fibonacci Sequence Generator – C# Console App

Welcome to FiboFlow, a beautifully simple yet powerful Fibonacci sequence generator written in pure C#.
This project is perfect for beginners who want to understand loops, sequences, and algorithmic thinking — all wrapped in a clean and stylish console application. 💻🌙


🚀✨ Features

✨ Generate Fibonacci numbers up to any count
✨ Super clean and readable C# code
✨ Fast, lightweight & beginner-friendly
✨ Runs on any .NET console environment
